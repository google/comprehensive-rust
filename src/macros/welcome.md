# Welcome to Macros in Rust

Welcome to the course on **Macros in Rust**. Macros are a powerful tool for
meta-programming, allowing to abbreviate and generate code without runtime
overhead.

In this course, we will cover:

- What macros are and why they are useful.
- The distinction between **declarative** and **procedural** macros.
- How the compiler processes tokens and constructs syntax trees.
- How to define Macros By Example and how they are matched, and expanded.
- Advanced declarative macro techniques.
- Macro hygiene and scoping.
- How to write procedural macros, along with typical structure and patterns.
